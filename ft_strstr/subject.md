# ft_strstr

> Reconstruction note: This subject was reconstructed from the repository implementation and is not presented as an official original subject.

## Assignment

Reproduce the behavior of `strstr`: locate the first occurrence of `to_find` in `str` and return a pointer to it. Return a null pointer if it is not found. If `to_find` is empty, return `str`.

## Prototype

```c
char *ft_strstr(char *str, char *to_find);
```
