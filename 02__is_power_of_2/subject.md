# is_power_of_2

## Assignment

Write a function that determines whether a given number is a power of 2. Return `1` if it is a power of 2; otherwise return `0`.

## Prototype

```c
int is_power_of_2(unsigned int n);
```

## Expected file

```text
is_power_of_2.c
```

## Allowed functions

```text
None
```
