# epur_str

## Assignment

Write a program that takes a string and displays it with exactly one space between words, with no spaces or tabs at the beginning or end, followed by a newline.

A word is a part of a string delimited by spaces or tabs, or by the beginning or end of the string.

If the number of arguments is not 1, or if there are no words to display, display only a newline.

## Expected file

```text
epur_str.c
```

## Allowed functions

```text
write
```
