# paramsum

## Assignment

Write a program that displays the number of arguments passed to it, followed by a newline. If there are no arguments, display `0` followed by a newline.

## Expected file

```text
paramsum.c
```

## Allowed functions

```text
write
```

## Examples

```console
$ ./paramsum 1 2 3 5 7 24
6
$ ./paramsum 6 12 24 | cat -e
3$
$ ./paramsum | cat -e
0$
```
