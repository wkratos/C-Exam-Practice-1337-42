# alt_case

> Reconstruction note: This subject was reconstructed from the repository implementation and is not presented as an official original subject.

## Assignment

Write a program that takes one string and alternates the case of its words. Words in odd positions are converted to lowercase and words in even positions are converted to uppercase. Words are delimited by spaces or tabs; other characters remain unchanged.

Display the resulting string followed by a newline. If the number of arguments is not 1, display only a newline.

## Expected file

```text
alt_case.c
```

## Allowed functions

```text
write
```
