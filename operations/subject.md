## Assignment

Write four functions that perform integer addition, subtraction, multiplication, and division.

`ft_add` returns `a + b`, `ft_sub` returns `a - b`, and `ft_prod` returns `a * b`. `ft_div` returns the integer quotient `a / b`; when `b` is zero, it returns `-1`.

## Prototypes

```c
int ft_add(int a, int b);
int ft_sub(int a, int b);
int ft_prod(int a, int b);
int ft_div(int a, int b);
```
