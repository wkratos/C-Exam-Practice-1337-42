# rstr_capitalizer

## Assignment

Write a program that takes one or more strings and, for each argument, puts the last character of each word in uppercase if it is a letter and the remaining letters in lowercase, then displays the result followed by a newline.

A word is a section of string delimited by spaces or tabs, or by the beginning or end of the string. If a word has a single letter, it must be capitalized.

If there are no arguments, display only a newline.

## Expected file

```text
rstr_capitalizer.c
```

## Allowed functions

```text
write
```
