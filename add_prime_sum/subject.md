# add_prime_sum

## Assignment

Write a program that takes a positive integer as an argument and displays the sum of all prime numbers less than or equal to it, followed by a newline.

If the number of arguments is not 1, or the argument is not a positive number, display `0` followed by a newline.

Yes, the examples are correct.

## Expected file

```text
add_prime_sum.c
```

## Allowed functions

```text
write, exit
```

## Examples

```console
$ ./add_prime_sum 5
10
$ ./add_prime_sum 7 | cat -e
17$
$ ./add_prime_sum | cat -e
0$
```
