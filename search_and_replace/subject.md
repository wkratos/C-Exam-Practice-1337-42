# search_and_replace

## Assignment

Write a program called `search_and_replace` that takes three arguments: a string, a character to replace, and the replacement character.

Replace occurrences of the second argument in the first string with the third argument. If the character is not present in the first string, print the original string.

If the argument count is incorrect, print only a newline. End the output with a newline.

## Expected file

```text
search_and_replace.c
```

## Allowed functions

```text
write
```
