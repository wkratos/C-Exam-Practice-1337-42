# expand_str

## Assignment

Write a program that takes a string and displays it with exactly three spaces between each word, with no spaces or tabs at the beginning or end, followed by a newline.

A word is a section of string delimited by spaces or tabs, or by the beginning or end of the string.

If the number of arguments is not 1, or if there are no words, display only a newline.

## Expected file

```text
expand_str.c
```

## Allowed functions

```text
write
```
