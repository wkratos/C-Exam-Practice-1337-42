# inter_space

> Reconstruction note: This subject was reconstructed from the repository implementation and is not presented as an official original subject.

## Assignment

Write a program that takes one string and displays its alphabetic characters with a single space after each displayed character except when the source character is the final character in the string. Non-alphabetic characters are not displayed.

If the number of arguments is not 1, display nothing.

> The implementation does not establish any required trailing newline behavior.

## Expected file

```text
inter_space.c
```

## Allowed functions

```text
write
```
