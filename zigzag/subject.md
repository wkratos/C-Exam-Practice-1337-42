# zigzag

> Reconstruction note: This subject was reconstructed from the repository implementation and is not presented as an official original subject.

## Assignment

Write a function that displays a string while alternating the case of its characters by zero-based position: alphabetic characters at even indexes are uppercase and alphabetic characters at odd indexes are lowercase. Non-alphabetic characters remain unchanged.

The function writes the result directly to standard output.

> The implementation does not establish required newline behavior or a safe contract for a null pointer.

## Prototype

```c
void zigzag(char *str);
```
