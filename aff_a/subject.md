> Reconstruction note: This subject was reconstructed from the repository implementation and is not presented as an official original subject.

## Assignment

Write a program that takes a string and displays the first `a` character it encounters, followed by a newline. If the string contains no `a`, display only a newline.

If the number of arguments is not 1, display `a` followed by a newline.
