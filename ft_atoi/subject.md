# ft_atoi

> Reconstruction note: This subject was reconstructed from the repository implementation and is not presented as an official original subject.

## Assignment

Write a function that converts the initial portion of a string to an integer.

Skip leading ASCII whitespace characters (`' '`, `\t`, `\n`, `\v`, `\f`, and `\r`), accept an optional sign, then convert consecutive decimal digits. Stop at the first non-digit and return the signed result.

> The implementation only handles a leading minus sign; the exact intended behavior for a leading plus sign and integer overflow cannot be established from it.

## Prototype

```c
int ft_atoi(char *str);
```
