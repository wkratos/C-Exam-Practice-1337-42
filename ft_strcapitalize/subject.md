# ft_strcapitalize

> Reconstruction note: This subject was reconstructed from the repository implementation and is not presented as an official original subject.

## Assignment

Write a function that capitalizes the first letter of each word and converts the remaining letters of each word to lowercase.

A word is a sequence of alphanumeric characters. Return the supplied string after modifying it in place.

## Prototype

```c
char *ft_strcapitalize(char *str);
```
