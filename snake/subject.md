# snake

> Reconstruction note: This subject was reconstructed from the repository implementation and is not presented as an official original subject.

## Assignment

Write a program that takes one string and converts an underscore-separated identifier to lower camel case: underscores are removed, the letter following each underscore is capitalized, and other uppercase letters are converted to lowercase.

If the number of arguments is not 1, display nothing.

> The implementation does not establish required newline behavior or behavior for malformed inputs such as consecutive or trailing underscores.

## Expected file

```text
snake.c
```

## Allowed functions

```text
write
```
