# ft_itoa

## Assignment

Write a function that takes an `int` and converts it to a newly allocated, null-terminated string. The function returns the result in a character array that you must allocate.

The conversion must handle zero, positive and negative values, and the complete `int` range, including `INT_MIN`.

## Prototype

```c
char *ft_itoa(int nbr);
```

## Expected file

```text
ft_itoa.c
```

## Allowed functions

```text
malloc
```
