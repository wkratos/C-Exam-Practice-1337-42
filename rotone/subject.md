# rotone

## Assignment

Write a program that takes a string and displays it, replacing each alphabetic character with the next letter in alphabetical order.

`z` becomes `a` and `Z` becomes `A`. Case remains unchanged. Non-alphabetic characters remain unchanged.

The output is followed by a newline. If the number of arguments is not 1, display only a newline.

## Expected file

```text
rotone.c
```

## Allowed functions

```text
write
```

## Examples

```console
$ ./rotone "abc"
bcd
$ ./rotone | cat -e
$
```
