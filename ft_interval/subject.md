# ft_interval

## Assignment

Write a program that takes a single string as an argument and prints the string character by character, applying these transformation rules according to each character's zero-based index:

- If the index is divisible by both 3 and 5, replace the character with `5`.
- Otherwise, if the index is divisible only by 3, replace the character with `5`.
- Otherwise, if the index is divisible only by 5, replace the character with `3`.
- Otherwise, keep the character unchanged.

Print the resulting string followed by a newline. If the number of arguments is not 1, print only a newline.

## Expected file

```text
ft_interval.c
```

## Allowed functions

```text
write
```
